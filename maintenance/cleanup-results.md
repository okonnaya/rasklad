# Результаты уборки

11 сентября 2026.

## Выполнено

- Футер на всех страницах с футером: HSE ADC, звезда, новые ссылки на «настя м.», «карина р.», «маша в.». Три отдельные копии заменены общим шаблоном.
- Поиск работает без необязательных полей, учитывает регистр, ё/е, HTML-сущности и пробелы. Повторный поиск не создаёт новые React roots и не перезагружает страницу. Назад/вперёд восстанавливают запрос.
- Исправлены ссылки статей, каталогов и карт. Запись «на работу» не имеет готовой страницы, поэтому ведёт в общий каталог раскладов.
- Каталог перестал запускать код поиска; фильтры проверяют наличие контейнера.
- Удалены учебный рандомизатор названий, неиспользуемый jQuery, мёртвые JS-компоненты и закомментированная логика. Код трёх раскладов объединён. Python-прототип и его данные сохранены.
- Обновлены React, Webpack, Babel, загрузчики и официальные GitHub Actions; удалены неиспользуемые Airtable/axios, file-loader и deprecated Babel plugin. Один lockfile npm.
- Webpack: 95 уникальных страниц плюс 2 сохранённых старых адреса, явный список страниц, общий runtime и библиотечные chunks, минификация JS и чистый output.
- Мини-каталог генерируется из SQLite; полные толкования загружаются только на страницах карт. Нет динамического require всей папки JSON.
- Изображения карточек загружаются лениво, шрифты используют swap. Canvas ограничен одним обновлением на кадр и учитывает reduced motion.
- Кнопки поиска/меню доступны с клавиатуры. Медиазапросы используют ширину окна, а не устройства.
- Добавлены ESLint, форматирование, тесты логики и SQLite, проверка ресурсов 97 HTML-страниц и CSS, CI на Linux.
- Проверенные npm audit исправления: 39 → 0 известных уязвимостей.

## Проверки и ограничения

- npm run check: lint, 5 JS-тестов, 5 SQLite-тестов, production build, ссылки на JS/CSS/изображения/шрифты.
- Браузер: поиск карты и статьи, повторный поиск без результатов, карта дня и раскрытие толкования; мобильное меню (открытие/закрытие), футер и главная на узком и широком экране. Исправлено наложение заголовка на описание, скрытые пункты меню исключены из навигации клавиатурой.
- Webpack сохраняет предупреждения о крупных исходных картинках, шрифте emoji и суммарном размере некоторых входных точек. Перекодирование медиа и переработка большого общего CSS в эту уборку не включены.
- ESLint 9 сохранён из-за peerDependencies eslint-plugin-react (поддерживает до 9); переход на 10 требует смены React lint-плагина.
- В старых трёх раскладах сохранён одинаковый редакционный текст, а Flask-прототип не подключён к сайту. Токен Airtable остаётся локальным; его прежний ответ 401 не исправляется обновлением зависимостей.
- Core Web Vitals/Lighthouse не измерены: Chrome DevTools MCP отсутствует.
